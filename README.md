# Lo he hecho

Listas de comprobación para las dudas de siempre (la llave, los fuegos, la plancha...), con la hora de cada marca, foto opcional como prueba e historial.

Sitio: https://adrianezd.github.io/lo-he-hecho/

- Rutinas editables (Salir de casa, Antes de dormir, Coche...). Cada marca caduca sola pasadas las horas de la rutina.
- Por defecto se marca manteniendo pulsado, para que el gesto sea consciente y se recuerde mejor. Se puede cambiar en Editar.
- Estado e historial en localStorage (`lo-he-hecho-v1`). Las fotos de prueba, solo la última de cada comprobación, en IndexedDB (`lo-he-hecho`).
